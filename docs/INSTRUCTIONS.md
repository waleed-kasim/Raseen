# General Project Instructions & Guidelines

## Design Philosophy
1. **Mobile First**: The primary focus is the mobile experience. Desktop is secondary.
2. **Responsive & Adaptive**: Layouts must handle all screen sizes gracefully, especially very small screens (< 350px).
3. **Flexibility**: Do not stick to a broken design; if a layout doesn't work on mobile, change it completely (e.g., Grid -> List).

## Technical Standards
- **Framework**: React + Bootstrap (currently).
- **Styling**: Prioritize utility classes but allow custom CSS for fine-tuning.
